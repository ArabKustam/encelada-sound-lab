# Encelada Sound Lab

Мастерская звука: музыка по нотам, биты, ремиксы, звуковые эффекты (SFX) и экспорт в Minecraft.
Работать можно в веб-приложении, из командной строки или через MCP (Claude пишет и правит звуки сам, а вы видите это в ленте).

**Полное руководство: [GUIDE.md](GUIDE.md)** — нотация, аккорды, ударные, сэмплы, ремиксы, эффекты, экспорт, все MCP-инструменты, примеры.

## Как это устроено

- Звук хранится как **рецепт** (JSON): темп, дорожки, эффекты, автоматизация, форма песни.
- Рецепт — источник правды. Движок каждый раз заново превращает его в звук; библиотека хранит рецепт, аудио (wav/ogg/моно-ogg), волну, спектрограмму, анализ и историю версий.
- Рецепты пишутся компактно:

```json
{"name": "demo", "tempo": 90, "key": "A minor", "tracks": [
  {"name": "drums", "kit": "808", "drums": {"kick": "x..x..x...x.....", "snare": "....x.......x...", "hat": "x.x.x.x.x.xRx.x."}, "loop": 4},
  {"name": "keys", "instrument": "electric piano", "chords": "i VI III VII", "style": "pulse"},
  {"name": "lead", "instrument": "скрипка", "notes": "A4:1/2 C5 E5 D5 C5:1 A4 . G4:1/2 A4:2.5"}
]}
```

## Запуск

- **Windows:** `Start-SoundLab.cmd` (в первый раз сам создаст `.venv` и поставит зависимости) → http://127.0.0.1:4790.
- **Вручную:** `python -m venv .venv`, `.venv\Scripts\pip install -r soundlab/requirements.txt`, `.venv\Scripts\pip install --no-deps tinysoundfont`, затем `.venv\Scripts\python -m soundlab.server` из папки `Encelada-Sound-Lab`.

## Что умеет
- **Нейросети (локально, RTX GPU):** ACE-Step 1.5 — готовые песни с живым вокалом по описанию стиля и тексту (японский, английский, русский и ещё 50 языков), каверы моих аранжировок и правка фрагментов; SoulX-Singer — нейро-певица поёт мои ноты точно по партитуре (соло, ансамбль, мужской голос); Woosh (Sony AI) — любой звуковой эффект по описанию. Установка: `python -m soundlab.install neural`.
- **Рояль:** Salamander Grand Piano (Yamaha C5, 16 слоёв силы удара) — инструмент `piano` по умолчанию.

- **Живые инструменты:** настоящие записи оркестра Sonatina (SFZ-сэмплер): рояль, скрипка (sustain, legato, staccato, pizzicato, tremolo), альт, виолончель, контрабас, струнные, флейта, гобой, кларнет, фагот, труба, валторна, тромбон, туба, арфа, клавесин, орган, **настоящий хор**, перкуссия — 298 вариантов; плюс 128 инструментов General MIDI из SoundFont MuseScore General (гитары, бас, саксофон…). Имена по-английски и по-русски: `скрипка`, `рояль`, `хор`.
- **Пение и фразы:** настоящий человеческий голос поёт мелодию слогами (`"lyrics": "ля ля ля"`, любые слова), соло или хором (8 голосов, мужские/женские/детские тембры); фразы голосом (`tts:Привет, путник`) для обработки в SFX.
- **Ноты:** мелодии строкой (`"C4:1 E G [C4 E G]:2 (A B)x2"`), аккорды по буквам и ступеням (`Am F C G`, `i iv V7`) с арпеджио/боем/басом, слои инструментов, синтезаторы, нотные блоки Minecraft, любой сэмпл как инструмент.
- **Биты:** сетки ударных (`x...x...`), наборы synth / 808 / GM / нотные блоки / свои сэмплы, свинг, роллы, sidechain; генератор стартовых битов (lofi, trap, house, rock, chiptune, noteblock).
- **Форма песни:** секции, партии по секциям, аранжировка (`intro verse chorus*2`).
- **База звуков:** 4000+ ванильных звуков Minecraft из установленной игры, своя папка `samples/`, библиотека; поиск и прослушивание.
- **Ремиксы:** импорт MIDI, нарезка аудио на срезы и перестановка, подгонка под темп, высота, реверс.
- **SFX:** 19 генераторов (крик, скрежет, рык, шёпот, ветер, удар, глитч, НЛО, «души»…), слои с ванильными звуками.
- **Эффекты:** реверб, эхо, перегруз, bitcrush, фильтры, EQ, pitch/stretch, sidechain, lofi, хорус, вибрато, компрессор, лимитер и др.; автоматизация по долям.
- **Анализ:** громкость по времени, баланс частот, темп, тональность, высота сэмпла, клиппинг, тишина — и замечания словами.
- **Экспорт:** в ресурспак Minecraft (`sounds.json`, моно/стерео, stream, случайные вариации), в файл, в MIDI.
- **ElevenLabs (необязательно):** звуки и музыка по текстовому описанию, если задан API-ключ.

## Claude через MCP

Сервер уже подключён к Claude Code (уровень пользователя). Подключить заново:

```
claude mcp add soundlab -s user -- "<папка>\.venv\Scripts\python.exe" "<папка>\soundlab\mcp_server.py"
```

Основные инструменты: `guide`, `catalog`, `create_sound`, `edit_sound`, `preview`, `search_samples`, `sample_info`, `analyze_sound`, `compose_beat`, `transform_audio`, `import_midi`, `export_to_minecraft`. Полный список — в GUIDE.md.

## Командная строка

```
python -m soundlab.cli beat lofi
python -m soundlab.cli render recipe.json
python -m soundlab.cli search zombie hurt --mc
python -m soundlab.cli export <id> drugs:halluc.name <папка пака> --variants=3
python -m soundlab.cli guide аккорды
```

## Папки

- `library/` — звуки (рецепт, аудио, картинки, анализ, история); удалённые — в `library/.trash`.
- `samples/` — ваши сэмплы (wav/ogg/flac/mp3), видны в поиске как `samples:путь`.
- `instruments/` — библиотеки живых инструментов (SFZ); скачиваются командой `python -m soundlab.install` (в git не хранятся).
- `soundfonts/` — SoundFont для GM-инструментов (MuseScore General, запасной TimGM6mb).
- `cache/tts/` — озвученные слоги и фразы.
- `exports/` — готовый ресурспак по умолчанию.
